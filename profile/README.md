**So, what is DJI Pilot 2, exactly?**
DJI Pilot 2 is a drone flight control app for Windows that lets pilots monitor a live camera feed, flight telemetry, and mission-planning tools for compatible DJI aircraft. DJI Pilot 2 for Windows brings all of that together on one screen — a DJI Pilot 2 desktop experience built so pilots aren't juggling separate apps mid-flight.

### Is DJI Pilot 2 right for you?
If you fly a compatible DJI aircraft and want video, telemetry, and mission planning in one place, it's built for exactly that. Its feature set includes:
* Live HD video streamed from the aircraft's camera
* Real-time flight telemetry: altitude, speed, battery, and signal strength
* Waypoint and route mission planning tools
